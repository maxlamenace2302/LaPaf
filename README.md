# La Petite Auberge de Flo

Site vitrine et système de réservation pour le restaurant **La Petite Auberge de Flo** à Saint-Bonnet-les-Oules (42330).

## Stack

- HTML / CSS / JavaScript natif (pas de build)
- Quatre langues : FR / EN / DE / IT
- Déploiement : [Vercel](https://vercel.com)

## Pages

- `index.html` — accueil
- `carte.html` — carte du restaurant
- `reservation.html` — formulaire de réservation
- `mentions-legales.html` — mentions légales
- `politique-confidentialite.html` — politique de confidentialité RGPD

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir [http://localhost:8000](http://localhost:8000).
